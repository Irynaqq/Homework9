# Refactoring “Simple Site” with SCSS

Проєкт виконано в рамках задачі з рефакторингу існуючого CSS-коду до сучасної, модульної структури SCSS.  
Мета — підвищити ефективність, читабельність та підтримуваність стилів, застосувавши змінні, міксіни, медіа-міксіни, вкладеність та модульність.

---

## 🎯 Основні завдання рефакторингу

### ✔ Перехід з CSS на SCSS  
Усі наявні стилі перенесено у SCSS-файли з подальшою компіляцією у `css/style.css`.

### ✔ Декомпозиція коду  
Стилі розбиті на логічні модулі:

scss/
utils/ – змінні, міксіни, медіа-міксіни
base/ – базові стилі (reset, typography)
layout/ – структура сторінки (header, footer, container)
components/ – компоненти (hero, navbar, section, experience, video)
main.scss – точка входу (@use)


### ✔ Використання SCSS-змінних  
Файл `_variables.scss` містить:

- кольори  
- типографічні налаштування  
- відступи (gap)  
- ширини контейнерів  
- значення line-height та font-weight  

### ✔ Використання міксінів  
Файл `_mixins.scss` включає:

- `flex-center` – для швидкого центрування  
- `button-primary` – стилі кнопок  
- `visually-hidden` – доступність  

### ✔ Медіа-міксіни  
Файл `_media.scss` містить адаптивні міксіни:

- `@mixin mobile`  
- `@mixin tablet`  
- `@mixin desktop`

### ✔ Вкладеність селекторів  
Стилі компонентів переписано з використанням SCSS-вкладеності для підвищення читабельності.

---

## 🚀 Компіляція SCSS → CSS

Для компіляції використано Sass:

sass scss/main.scss css/style.css --watch
